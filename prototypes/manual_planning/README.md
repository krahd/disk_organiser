# Manual storage planning fixtures

These files are illustrative, user-authored planning metadata. They are not drive
observations, authenticated backup evidence or executable instructions. Paths and
provider descriptions remain inert text.

The schema is the reviewed v1 design with a pre-publication immutable historical
context extension, embedded in
`frontend/manual-planning-model.js`. The model adds bounded lexical, semantic,
reference and history validation. See
[`docs/manual-planning/MODEL.md`](../../docs/manual-planning/MODEL.md) for the API,
representation limits, warnings and complete import/edit/export contract.

The empty example is a valid document. The photo examples intentionally retain
unknown sizes, versions, descendant membership and coverage. The result example
records a sample-readability pass and metadata failure separately; neither is a
verified restore.
