Organise your disk without risky one-way changes

Disk Organiser combines duplicate search, visualisation, and AI-assisted planning into one local-first workflow. You can preview every action, create backups before execution, and undo in reverse order.

What it does

  • Scans selected roots and visualises file distribution.
  • Finds duplicate groups using content-aware signals.
  • Builds typed actions for safe reorganisation.
  • Supports local and cloud model suggestions.

Safety model

  • Preview mode before execution.
  • Backups captured before changes.
  • Undo restores operations in reverse execution order.
  • Path validation keeps actions in allowed roots.

Run locally

python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
python -m backend.app
npm install
npm run start

Run backend and frontend in separate terminals for the full experience.
