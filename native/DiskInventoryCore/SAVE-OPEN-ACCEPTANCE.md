## User flows and boundaries verified

- Save captures the current catalogue, completes owned storage before page acknowledgement, and does not silently save temporary project selections or unfinished edits.
- A lost acknowledgement exposes a same-attempt Check action. Recovery does not create a second saved version; newer edits remain dirty.
- Open lists the complete bounded set, validates the selected bytes and previews all recorded locations before explicit replacement. Cancel preserves current catalogue, selections, edits and focus.
- Replacement discloses loss of unsaved catalogue edits and temporary selection/search/comparison state. Uncertain replacement/cancellation stays fenced until its exact attempt is resolved.
- Close preserves drafts, discloses selection loss and offers applicable Save/Check/Keep choices. Saved versions are retained and never overwritten.
- One owned storage actor has one lifetime interaction owner, including across distinct injection wrappers. The 128-preview budget refuses further selection explicitly; no history is silently evicted.
- Native pointer and keyboard journeys retain real AppKit/WebKit events, readiness, hit testing and focus assertions. No JavaScript click substitutes for a failed native action.

The earlier top-origin follow-up exposed an actual first-button frame of `(-7, -5, 201, 32)` outside its document. Internal eight-point stack padding fixes the layout while preserving the test. Both final runs measure `(1, 3, 185, 32)` wholly inside visible regions `(0, 0, 203, 253)` or `(0, 0, 203, 238)`. Positive dimensions, full-frame containment and the maximum 16-point top gap pass unchanged. All 58 emitted native hit/visible-centre checks pass in each run.
